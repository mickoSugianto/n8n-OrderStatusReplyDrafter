Built to fail safely, and honest about limits.

Every reply passes deterministic checks before it is drafted.

Drafts only

No node in the workflow sends customer emails.

Exact lookup

Order matching is rule-based. The AI extracts the question and writes prose from verified facts. Missing or unknown numbers use fixed templates.

People handle exceptions

Refunds, multiple orders, conflicting info and unusual requests go to you.

Failures stay visible

If something fails halfway, the work is kept for inspection instead of retried blindly, so a retry can’t create duplicate drafts.

What the AI sees

The customer’s question and, for a verified match, that one order’s details are sent to the AI providers (Groq, with OpenRouter as fallback) to write the draft.

What it doesn’t do

  • Synthetic test data. Built and tested on synthetic orders and two controlled accounts, not live customer traffic.
  • Plain-text English, one order per email. No attachments or multi-order requests.
  • A consistency check, not authentication. Sender matching does not prove who the customer is.
  • A person reads every draft. It does not replace review before sending.
  • No automatic recovery or dashboard. Uncertain writes pause for manual inspection.

Walkthrough summary (text alternative)

Covers the 9-phase main workflow, the isolated GetOrder lookup contract, the PostgreSQL state machine keyed on (mailbox, source_message_id), draft-intent recording before Gmail is called, and the offline and live verification suites.

Key design decisions

  • Deterministic lookup, LLM limited to extraction and drafting. Exact matching and sender checks run in code before any order facts reach a prompt.
  • Atomic PostgreSQL claim per mailbox and message. A composite key stops concurrent polls from drafting twice.
  • Checkpoints, readback and safe recovery. Draft intent is saved before Gmail is called, the draft is read back to verify it, and a draft is never re-created when the outcome is uncertain.
  • Human review gate on every reply. Refunds, prompt overrides, multi-order emails and sender mismatches go to manual review.
